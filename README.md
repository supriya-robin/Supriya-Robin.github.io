# Supriya S P & Robin R — Wedding Invitation Website

A mobile-first wedding invitation website for 20 December 2026.

## Publish on GitHub Pages
1. Upload `index.html`, `README.md`, and the complete `assets` folder to the root of your existing repository `Supriya-Robin-Wedding`.
2. Keep the repository's GitHub Pages setting on **Deploy from a branch → main → /(root)**.
3. Wait a minute or two, then open the same website link and refresh.

## Included
- Elegant opening cover and invitation reveal
- Wedding date scratch-to-reveal card with petal animation
- Countdown to the ceremony
- Bride, groom, and couple photos
- Gallery
- Venue details and Google Maps search link
- RSVP link connected to the Google Form
- Bridal piano MP3 with play/pause control
- Share button

## Editable details
Open `index.html` and find the `CONFIG` object near the bottom to edit names, date, time, venue, map URL, RSVP URL, or music file path. If you add future photos, upload them to `assets/` and add their matching `<img>` tags in the gallery markup.

## RSVP
Responses are collected through the Google Form and its linked Google Sheet. The form URL is already configured in the website.

## Music
Mobile browsers may block autoplay. The music starts when a guest taps **Open Invitation**, and guests can pause or resume it using the floating music button.
